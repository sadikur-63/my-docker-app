# Dockerized Flask Web Application

A simple, lightweight Python web application built with Flask and containerized using Docker. This repository demonstrates how to package a web service into a Docker container and deploy it automatically to cloud hosting platforms like Render.

---

## 🛠️ Project Structure

```text
my-docker-app/
├── app.py              # Main Flask application file
├── Dockerfile          # Container configuration and build instructions
├── requirements.txt    # Python package dependencies
└── README.md           # Project documentation
